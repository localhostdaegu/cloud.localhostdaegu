# Mint Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Track each task with the plan ledger.

**Goal:** Ship the approved mint/dark-green homepage with a Blender pin, useful product previews, and a responsive shared header while preserving the existing intent funnel.

**Architecture:** Retain ChatLanding's state and routing, compose a static hero visual beside its form, and scope landing layout in a CSS module. Shared tokens and the existing header apply branding to the current application without changing APIs.

**Tech Stack:** Next.js 16.3.2, React 19, Tailwind 4, CSS modules, Vitest, Playwright, Blender 5 background render.

**Spec:** `docs/superpowers/specs/2026-09-17-mint-home-design.md`

- Read root and frontend AGENTS.md and local Next.js documentation before editing.
- No backend changes, dependency additions, visible browser, or browser-opening startup commands.
- Preserve existing intent API/URL behavior, theme support, keyboard access, reduced-motion support.
- Main palette: brand mint #34C8B0, deep green #004D46, soft mint #E8F7F2, canvas #F7F8F3. Use dark foreground on mint controls. Use a distinct darker accent for readable text links.
- Keep placeholder “예: 서문시장 근처 카페, 예산 5천”, button “찾아보기”, and existing example chip copy compatible with the current funnel.
