# localhostdaegu 민트 홈 디자인

사용자는 2026-09-17 브레인스토밍에서 주최 측 민트 톤을 반영한 밝은 금융 서비스 방향을 승인하고, 서브에이전트 방식으로 즉시 구현하도록 요청했다.

## 목표와 범위

현재 작은 입력창 중심의 홈을 서비스의 가치와 결과를 이해할 수 있는 브랜드 랜딩으로 변경한다. 첫 적용 범위는 홈, 공통 색상, 모바일 헤더다. 기존 intent → map → simulate 흐름과 API 계약은 유지한다. 내부 지도·재무 화면의 레이아웃 개편과 백엔드 작업은 이번 범위에 없다.

## 시각 방향

- 배경 `#F7F8F3`, 브랜드 민트 `#34C8B0`, 딥그린 `#004D46`, 연민트 `#E8F7F2`.
- 민트는 첨부 이미지의 프로파일을 sRGB로 변환해 얻은 디자인 기준이며 공식 CI 값이라고 표기하지 않는다.
- 읽기용 강조색은 대비가 충분한 진한 청록을 별도로 유지한다. 민트 버튼에는 진한 글씨를 쓴다.
- Astryx의 큰 타이포그래피, 넓은 여백, UI 카드를 활용한 제품 설명에서 구성 원칙을 참고한다.
- 데스크톱은 왼쪽 메시지/입력, 오른쪽 입체 BI 핀/지도 형태/미리보기 카드. 모바일은 입력을 먼저 보여주고 비주얼과 기능 카드를 아래로 쌓는다.
- 제목: “대구에서 여는 내 가게, 상권부터 자금까지.” 작은 소개 문구: “대구 창업 금융 네비게이터”.
- 투명 배경의 입체 핀 이미지는 설치된 Blender의 background 렌더로 제작한다. 실시간 3D 런타임과 신규 패키지는 추가하지 않는다.
- 원본 BI 워드마크는 헤더에 유지한다. 입체 핀은 BI의 원형 핀, 터미널 기호, 사각형을 활용한다.
- 하단은 지도 탐색/비용 계산/자금 계획의 세 흐름을 크기가 다른 카드로 보여준다. 출처와 기준일은 확인된 정보만 표시한다. 모든 가상 결과에는 “예시”를 표시하며 실제 금융상품 연결/리포트 완성을 과장하지 않는다.

## 동작과 접근성

- 기존 예시 질문, 빈 입력 비활성화, pending, error, 업종 추가 질문, 업종 건너뛰기, URL 라우팅을 유지한다.
- 기존 E2E의 placeholder “예: 서문시장 근처 카페, 예산 5천”와 제출 버튼 “찾아보기”를 유지한다.
- 버튼과 링크는 실제 동작 또는 경로를 가져야 한다. 장식 카드는 클릭 가능하게 꾸미지 않는다.
- 모바일 헤더는 320px에서도 메뉴 글자가 중간에서 줄바꿈되지 않으며 가로 스크롤이 생기지 않는다.
- 라이트/다크 테마, 키보드 포커스, reduced-motion을 지원한다. 장식 그래픽은 보조기술에서 숨긴다.

## 검증

Vitest, TypeScript, production build. 단일 헤드리스 Playwright 프로세스로 1440px/390px/320px에서 홈 라이트/다크와 모바일 헤더, 입력과 예시 질문 흐름을 확인한다. 기존 funnel 테스트의 여정도 검증한다. 사용자가 실행 중인 서버·브라우저를 종료하지 않는다.

## 구현 검증 기록

- Vitest 26파일 / 84테스트 통과, TypeScript 통과.
- 1440/1024/390/320px × 라이트/다크 검증 통과: 가로 넘침, 메뉴 줄바꿈, 이미지 로드, 키보드 동작, reduced-motion, 런타임 오류를 확인했다.
- 딥그린 카드의 포커스 대비와 지도 모식도 안내가 잘리지 않는지도 실제 브라우저에서 확인했다.
- 기존 intent → 지도 행정동 실제 클릭 → 시뮬레이션 결과까지 통과했다. 실행 중인 개발 서버를 재사용했고 테스트 브라우저만 종료했다.
- `npm run build -- --webpack` 배포용 빌드 통과. 기본 Turbopack은 이 실행 환경에서 CSS 변환용 내부 포트 생성이 거부되어 실패했다. 프로젝트 기본 빌드 설정은 변경하지 않았다.
- 화면 캡처: `/tmp/localhostdaegu-mint-checks/`. 재검증: 실행 중인 3300 서버에서 `node frontend/tests/home-design.cjs`, 기존 전체 여정은 `E2E_REUSE_SERVER=1 node frontend/tests/funnel.cjs`.
