# 금융상품 상담 메타데이터 원문 대조 기록 (2026-09-18)

전환계획 §10-3의 기록 항목을 따른다. **공식 원문에서 확인한 것만 적는다.**
확인하지 못한 항목은 빈칸이 아니라 "미확인"으로 남긴다 — 추정으로 채우면 상담 자리에서 사용자가 틀린 안내를 들고 가게 된다.

## 0. 이번 대조의 범위와 한계

- 대조 대상: 운영 JSON 12건 (`data/manual/*.json`)
- **실제로 원문을 연 것: 2건** (iM뱅크 상품 페이지 1, 매일신문 기사 1)
- **열지 못한 것: 대구신용보증재단(`dgsinbo.or.kr`) 전체** — TLS 인증서 체인 검증 실패(`unable to verify the first certificate`)로 접근하지 못했다. 재단 상품 5건과 재단 페이지를 출처로 둔 정책자금 2건이 여기 걸린다.
- 따라서 **12건 중 3건만 `consultation_metadata`가 있고 9건은 미확인**이다. 미확인 상품은 `GET /matching/consultation` 응답에 iM뱅크 상담 후보로 나오지 않는다(§5-2).
- 이 문서는 접수 가능 보장이 아니다. 확인일 이후 공고가 바뀔 수 있다.

## 1. 확인한 상품

### imbank-1 · imbank-2 — 소상공인시장진흥공단 정책자금 (운전자금 / 시설자금)

| 항목 | 내용 |
|---|---|
| 제공기관 | iM뱅크 |
| 공식 출처 | https://www.imbank.co.kr/cms/fnm/loan/product/giup/01/sda_41216/1221451_5612.html |
| 원문 게시일 | 2026-04-23 (페이지 표기) |
| 유효기간 종료 | 2028-03-31 (페이지 표기) |
| 확인일 | 2026-09-18 |
| 은행 연결 | `direct` — iM뱅크 자사 상품 페이지에 게시된 상품이다 |
| 선행 절차 | ① 소상공인시장진흥공단(지역센터 포함)에 신청 후 '정책자금 지원대상 확인서' 발급 ② 신용보증기관 연계 시 보증서 발급 |
| 신청 경로 | 은행 영업점에 정책자금 지원대상 확인서 제출 |
| 준비서류 | **미확인** — 페이지에 서류 목록이 없다 |
| 사업자등록 필요 여부 | **미확인** — "소진공에서 자금 추천을 받은 개인기업 또는 법인"이라고만 적혀 있고 등록 요건을 명시하지 않는다 |
| 금리 | 페이지에 2/4분기 기준금리 3.44% 표기가 있으나 **개인 적용금리가 아니다.** 운영 JSON의 `interest_rate`는 null로 유지한다 |
| 반영 위치 | `data/manual/imbank_products.json` → `product_consultation_metadata`·`product_procedure_step` |

운전자금과 시설자금은 같은 페이지를 출처로 하며 페이지가 둘을 구분해 설명하지 않는다. 두 건에 같은 메타데이터를 넣었고, 자금 용도별 차이는 상담에서 확인할 항목이다.

### imbank-3 — 소상공인 성장촉진 보증대출

| 항목 | 내용 |
|---|---|
| 제공기관 | iM뱅크 (보증: 신용보증재단중앙회) |
| 출처 | https://www.imaeil.com/page/view/2025113013422798725 (매일신문, 2025-11-30) |
| 확인일 | 2026-09-18 |
| 은행 연결 | `linked` — **`direct`로 올리지 않았다.** 기사 본문이 "전국 모든 iM뱅크 영업점에서 취급"이라고 적고 있으나 은행 자사 상품 페이지를 찾지 못했다. 언론 보도는 연계 근거로는 쓰되 자사 취급 고시와 동급으로 두지 않는다 |
| 선행 절차 | 기사에 따르면 보증재단 직접 방문이 불필요하다. 그 외 선행 절차 **미확인** |
| 신청 경로 | iM뱅크 영업점 방문 신청 |
| 준비서류 | **미확인** |
| 자격 | 소기업·소상공인. 경쟁력 강화 계획 입증(스마트화 도입, 지자체·재단 컨설팅 이수, 고용유지·창출, 매출 증가·사업장 확장 중 하나 이상). 사업자등록 요건은 **미확인** |
| 접수 가능 여부 | **미확인** — 기사 시점(2025-11-30)과 확인일 사이 변동 가능. 기사에 "내년 초 비대면 신청 시스템 도입 예정"이라는 계획이 있으나 현재 시행 여부는 확인하지 못했다 |

## 2. 확인하지 못한 상품 (9건)

모두 `consultation_metadata` 없음 = 미확인으로 남겼다.

| product_id | 제공기관 | 미확인 사유 |
|---|---|---|
| dgsinbo-1 ~ dgsinbo-4 | 대구신용보증재단 | `dgsinbo.or.kr` TLS 인증서 체인 검증 실패로 원문 접근 불가 |
| dgsinbo-5 | 대구신용보증재단 | 출처가 뉴스핌 기사이며 재단 원문 대조를 못 했다 |
| youth-1 | 대구 북구청·대구신용보증재단 | 기업마당 공고가 2025년 기준이다. 2026년 재공고 여부 미확인 |
| youth-2 | 중소벤처기업진흥공단 | 원문 미대조 |
| youth-3 · youth-4 | 대구광역시 (대구신보 추천) | 재단 게시판 URL로 접근 불가 |

**특히 dgsinbo-4(금융기관 특별출연 협약보증)는 이름상 은행 협약이 있을 가능성이 높지만, 근거를 열지 못했으므로 `linked`로 올리지 않았다.** 모든 보증·정책자금에 iM뱅크 연결을 자동 부여하지 않는다(§5-2).
