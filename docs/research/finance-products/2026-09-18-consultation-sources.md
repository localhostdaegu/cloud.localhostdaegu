# 금융상품 상담 메타데이터 원문 대조 기록 (2026-09-18)

전환계획 §10-3의 기록 항목을 따른다. **공식 원문에서 확인한 것만 적는다.**
확인하지 못한 항목은 빈칸이 아니라 "미확인"으로 남긴다 — 추정으로 채우면 상담 자리에서 사용자가 틀린 안내를 들고 가게 된다.

## 0. 이번 대조의 범위와 한계

> **2026-09-18 2차 갱신** — 대구신용보증재단 TLS 문제를 해결해 재단 4건을 추가로 대조했다. 아래 §1-2 참조.

- 대조 대상: 운영 JSON 12건 (`data/manual/*.json`)
- **원문을 연 것: 6건** — iM뱅크 상품 페이지 1(상품 2건), 매일신문 기사 1, 대구신보 보증상품 4
- **아직 못 연 것: 5건** — dgsinbo-5(뉴스핌 기사 출처), youth-1(기업마당 2025년 공고), youth-2(중진공), youth-3·4(재단 게시판)
- **12건 중 7건에 `consultation_metadata`가 있고 5건은 미확인**이다.
- **iM뱅크 상담 후보는 여전히 3건뿐이다.** 재단 4건은 원문을 확인했지만 취급 은행이 "시중은행"·"출연 금융기관"으로만 적혀 있어 `unverified`로 남았다 — 확인 못 한 것이 아니라 **확인했는데 은행 명시가 없다**.
- 이 문서는 접수 가능 보장이 아니다. 확인일 이후 공고가 바뀔 수 있다.

### TLS 문제 해결 방법 (재현용)

`dgsinbo.or.kr`은 **중간 인증서를 보내지 않는 서버 설정 오류**다(leaf 인증서만 전송). 검증을 끄지 않고 서버가 빠뜨린 중간 인증서를 보충해 정식으로 검증했다.

```bash
openssl s_client -connect www.dgsinbo.or.kr:443 -servername www.dgsinbo.or.kr </dev/null \
  | openssl x509 -out leaf.pem
openssl x509 -in leaf.pem -noout -ext authorityInfoAccess   # CA Issuers URI 확인
curl -s -o inter.crt http://crt.sectigo.com/SectigoPublicServerAuthenticationCADVR36.crt
openssl x509 -inform DER -in inter.crt -out inter.pem
cat inter.pem /etc/ssl/certs/ca-certificates.crt > bundle.pem
curl --cacert bundle.pem "https://www.dgsinbo.or.kr/..."   # HTTP 200
```

`--insecure`는 쓰지 않았다. 상품 상세는 래퍼 페이지(`/page/10039/10043.tc?...&gdsNo=N`)에 서버 렌더되며, 내부 경로 `/guaranteegoods/detail.tc`를 직접 부르면 404다.

## 1-2. 대구신용보증재단 4건 — 원문 확인, 은행 명시 없음

네 상품 모두 **취급은행 항목에 iM뱅크가 없다.** 따라서 `bank_connection`은 `unverified`이며 iM뱅크 상담 후보에 넣지 않았다. `none`(은행 취급 자체가 없음)이 아니라 **어느 은행인지 원문이 밝히지 않는 상태**다.

| product_id | 상품 | 취급은행 표기 | 사업자등록 필요 | 확인한 선행 조건 |
|---|---|---|---|---|
| dgsinbo-1 | 대구형 창업·성장 플러스 특별보증 (gdsNo=35) | **시중은행** | 미확인(‘기업’ 기준 서술만) | Track1 업력 3년 미만 / Track2 3년 이상 성장기업 / Track3 성실상환. 한도 1억, 보증료율 0.9% |
| dgsinbo-2 | 대구형 전통시장·골목상권 활력 특별보증 (gdsNo=36) | **시중은행** | 미확인 | 전통시장·상점가·골목형상점가·상권활성화구역 등에 사업장 소재. 한도 1억, 보증료율 0.9% |
| dgsinbo-3 | 유망 예비창업자 사전보증 (gdsNo=5) | **시중은행** | **아니오** — 예비창업자 대상 | 창업교육 10시간 이상 또는 컨설팅 2회·10시간 이상(최근 1년) 또는 최근 2년 내 지식재산권 사업화 / 대표자 신용평점 NICE 755·KCB 670 이상 / 통지일로부터 6개월 이내 사업자등록증 제출. 한도 5천만(교육·컨설팅)·7천만(지식재산권), 보증료율 0.80% |
| dgsinbo-4 | 금융기관 특별출연 협약보증 (gdsNo=30) | **출연 금융기관** | **예** — ‘대구광역시에 사업자등록을 한’ | 한도 4억, 보증료율 0.90%, 1년 만기일시 또는 5년 분할(1년거치) |

**dgsinbo-3이 이번 조사에서 가장 중요한 발견이다.** 우리 주 사용자(계약 검토 중인 예비창업자)가 사업자등록 전에 신청할 수 있는 유일하게 확인된 상품인데, iM뱅크 취급 근거가 없어 은행 상담 후보에는 넣을 수 없다. 그래서 §5-2가 허용하는 **‘관련 기관 참고자료’**로 화면에 따로 표시하도록 구현했다(`include_unverified=true`).

준비서류·신청 절차는 네 상품 모두 상세 페이지에 없어 `documents`·`application_steps`를 비워 뒀다. 화면에는 “공식 안내에서 확인 필요”로 표시된다.

## 2. 아직 확인하지 못한 상품 (5건)

모두 `consultation_metadata` 없음 = 미확인으로 남겼다.

| product_id | 제공기관 | 미확인 사유 |
|---|---|---|
| dgsinbo-5 | 대구신용보증재단 | 출처가 뉴스핌 기사이며 재단 원문 대조를 못 했다 |
| youth-1 | 대구 북구청·대구신용보증재단 | 기업마당 공고가 2025년 기준이다. 2026년 재공고 여부 미확인 |
| youth-2 | 중소벤처기업진흥공단 | 원문 미대조 |
| youth-3 · youth-4 | 대구광역시 (대구신보 추천) | 재단 게시판 URL 미대조 |

이 5건은 `consultation_metadata`가 없어 화면에서 **“공식 원문을 아직 확인하지 못함”**으로 표시된다. 원문을 보았으나 은행 명시가 없던 재단 4건(**“취급 은행이 명시되지 않음”**)과 문구로 구분한다 — 확인하지 않은 것을 확인한 것처럼 쓰지 않기 위해서다.

**dgsinbo-4(금융기관 특별출연 협약보증)는 이름상 은행 협약이 있어 보였으나, 원문 확인 결과 취급은행이 ‘출연 금융기관’으로만 적혀 있어 `linked`로 올리지 않았다.** 모든 보증·정책자금에 iM뱅크 연결을 자동 부여하지 않는다(§5-2).
